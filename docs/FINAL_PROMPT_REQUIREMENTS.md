# Final Prompt Upgrade Notes

The final prompt shifts ATLAS from a migration-only framing to a research-grade runtime for preserving and reasoning about data-system reality across transformation, evolution, and failure. The upgrade must preserve the existing vertical slice and honesty about unfinished integrations.

## New first-class requirements

The highest-value additions are a Data Genome, archaeology findings with epistemic status, an assumption ledger with knowledge decay, a typed Migration IR/compiler boundary, semantic and byte reconciliation, temporal/epistemic time, counterfactual and reconstruction proposals, provenance, richer certification, and a real TypeScript/React operator/research console.

The four language boundaries are deliberate: Python remains the canonical reference/research engine; .NET owns a production-shaped orchestration/control plane; Rust owns measurable deterministic performance kernels with a fallback; TypeScript/React owns the operator/research console.

Public-data connectors must use official APIs, immutable snapshots, explicit source metadata, and configurable providers. They must not fabricate live ingestion where the environment has not executed it. The UI must expose archaeology, genome, migration plan, execution, reconciliation, financial state, provenance, incidents, counterfactuals, public data, semantic drift, benchmarks, and certification without becoming a generic CRUD dashboard.

## Honesty constraints

No production-ready, exactly-once, million-TPS, bank-grade, or fabricated benchmark claims. Every new subsystem needs a precise model, implementation, test, measurable result, and limitation. Extension-only features must be labeled as such.

## Baseline issue to address

The existing final demo with 25 customers generates a deliberate duplicate customer key. The idempotent target collapses the duplicate, so direct row-count reconciliation reports a failure. The upgrade should not hide this. It should classify the duplicate as inherited integrity debt, reconcile the deduplicated canonical entity set explicitly, and show the debt in evidence/UI.
